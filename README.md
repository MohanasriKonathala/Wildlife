# WILDGUARD 🐾
### AI-Powered Wildlife Protection & Risk Prediction System

WILDGUARD is a hackathon prototype designed to improve wildlife safety by combining wildlife movement data, risk-zone prediction, village proximity, and ranger alerts in one dashboard.

## Problem
Wildlife entering areas close to villages can create safety risks for both animals and people. Rangers also need a faster way to identify high-risk areas and respond to incidents.

## Solution
WILDGUARD provides:
- Wildlife movement monitoring
- Low / Medium / High risk-zone visualization
- Village-boundary proximity awareness
- Emergency/ranger alerts
- Risk analytics dashboard
- A foundation for AI-based wildlife risk prediction

## Key Features
1. **Risk Prediction** – classifies areas into Low, Medium and High risk.
2. **Wildlife Tracking** – visualizes sample animal movement paths.
3. **Village Safety Layer** – highlights nearby settlements.
4. **Ranger Alerts** – displays priority incidents requiring attention.
5. **Analytics** – summarizes wildlife activity and current risk.

## Run Locally
No server is required for the prototype.

1. Download/clone the repository.
2. Open `frontend/index.html` in a browser.

For a local development server, you can use VS Code Live Server or:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000/frontend/`.
