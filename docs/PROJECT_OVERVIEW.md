# WILDGUARD — Project Overview

## Objective
Build an intelligent wildlife protection platform that helps authorities identify potentially dangerous wildlife activity and respond quickly.

## Users
- Forest/range officers
- Wildlife rangers
- Local administration
- Communities near forest boundaries

## Workflow
1. Collect wildlife movement/activity data.
2. Calculate a risk score.
3. Classify the location as Low, Medium or High risk.
4. Compare the location with nearby village boundaries.
5. Generate a ranger alert when risk becomes significant.
6. Display the situation on the dashboard.

## Prototype Note
The included dashboard uses sample data so that the project can be demonstrated without requiring live sensors or external APIs. The architecture is designed so a real ML model, GPS feed and notification service can be connected later.
